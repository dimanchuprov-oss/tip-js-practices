## 4. Задание 1: Различие результатов в двух средах

При запуске файла `hello.js` последняя строка выводит результат операции `typeof document`.

* **В браузере (Chrome Console):** Выводится `object`.
* **В среде Node.js (Терминал):** Выводится `undefined`.

**Причина различия:** 
Глобальный объект `document` является частью Web API и существует только внутри браузеров для взаимодействия со структурой веб-страницы (DOM). В серверной среде выполнения Node.js графическая страница и окна отсутствуют, поэтому объект `document` там не определен (`undefined`).

## 5. Задание 2: Исследование типов и преобразований

| **9** | `typeof null` | `object` | `"object"` | `string` | Историческая ошибка (баг) в спецификации языка JavaScript, где `null` ошибочно распознается как объект. Сам `typeof` всегда возвращает строку. |

### Исходный и исправленный результаты:
* **Фактический вывод (с ошибками):**
  ```text
  Выполнено: 32
  Осталось: -24
  Контрольная сумма: 6
  ```
* **Исправленный вывод:**
  ```text
  Выполнено: 5
  Осталось: 3
  Контрольная сумма: 10
  ```

### Таблица отладки

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
| :--- | :--- | :--- | :--- | :--- |
| **Обработка количества задач** | Выполнено: `32`<br>Осталось: `-24` | Строковые значения конкатенировались через оператор `+`, превращаясь в `"32"`, а не складывались как числа. | Добавлено явное приведение к числовому типу с помощью функции `Number()` перед сложением. | Выполнено: `5`<br>Осталось: `3` |
| **Граница цикла** | Контрольная сумма: `6` | Строгое условие `< 4` завершало цикл на значении `3`. Четвертая задача не включалась в сумму. | Изменено условие выхода на нестрогое равенство: `taskNumber <= 4`. | Контрольная сумма: `10` |
